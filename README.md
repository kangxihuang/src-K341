# (附文档)Springboot3+Vue3+MySQL 学分通-智能化学分管理与活动推荐系统

**技术栈**：Springboot3、Vue3、MySQL

### 系统简介

学分通-智能化学分管理与活动推荐系统是一套前后端分离的学分管理平台，采用SpringBoot3+Vue3+MySQL架构。系统面向高校学生与管理员两类角色，提供活动发布与报名、学分记录与统计、智能活动推荐、学分预警、通知公告等核心功能。系统基于JWT实现无状态认证，支持多维度数据统计与可视化分析，帮助高校实现学分管理的数字化与智能化。
 
### 核心功能
 
### 普通用户端

- 登录认证：支持用户名+密码登录，系统自动校验账号状态与角色类型，登录成功后签发JWT令牌并记录最后登录时间

- 活动浏览：分页浏览活动列表，支持按分类、状态、关键词筛选，展示活动封面、学分、时间、地点、人数限制等详细信息

- 智能活动推荐：根据学生各分类学分缺口情况，自动推荐符合学分需求的活动，按学分缺口优先级排序展示

- 活动报名：在线报名活动，系统自动校验活动状态、报名截止时间、人数上限及重复报名，报名成功后实时更新参与人数

- 我的报名：查看个人报名记录列表，展示活动标题、封面、学分、状态、审核意见等信息，支持按时间倒序排列

- 学分看板：展示各学分分类的已获得学分、要求学分、完成率及缺口学分，统计总已获得学分、总要求学分及整体完成率

- 学分记录：分页查看个人学分流水，支持按状态、学期筛选，展示学分值、分类名称、申请时间、审核时间及审核备注

- 学分预警：查看各分类学分缺口预警列表，按完成率自动划分danger/warning/info三级预警等级

- 学期筛选：获取个人学分记录中涉及的所有学期列表，用于快速筛选历史学分数据

- 个人资料：查看和编辑个人基本信息，包括姓名、邮箱、电话、头像、学院、专业等字段

- 修改密码：验证原密码后设置新密码，密码经BCrypt加密存储

- 通知中心：查看个人通知列表（含全局通知），支持单条标记已读、全部标记已读操作

- 学分分类查询：查看系统所有学分分类，包括分类名称、编码、颜色标识、要求学分及排序
 
### 管理员端

- 登录认证：支持管理员角色登录，系统校验账号角色与登录方式是否匹配，登录成功后返回管理员身份令牌

- 活动管理：创建活动，填写标题、分类、封面、学分值、起止时间、报名截止时间、人数上限、地点、组织方、标签等字段

- 活动编辑：修改活动基本信息，更新活动封面、时间、人数限制、状态等字段

- 活动删除：逻辑删除活动记录，删除后活动不再展示在列表中

- 活动状态管理：修改活动上下架状态，控制活动是否接受报名

- 活动列表管理：分页查看全部活动，支持按分类、状态、关键词筛选，展示活动完整信息

- 报名审核：查看全部报名记录，展示报名学生姓名、学号、学院、专业、报名时间、活动信息等详情

- 单条报名审核：审核通过/拒绝报名记录，填写审核意见，记录审核人与审核时间

- 批量报名审核：选择多条报名记录，统一审核通过或拒绝，批量填写审核意见

- 学分发放：对已审核通过的报名记录一键发放学分，自动生成学分记录并标记学分已发放

- 学分审核：审核学生学分记录，设置审核状态（通过/拒绝）并填写审核意见，记录审核人及时

- 学生管理：分页查看学生列表，支持按用户名或姓名模糊搜索，展示学生学号、学院、专业、班级、年级等信息

- 新增学生：创建学生账号，设置用户名、初始密码、姓名、邮箱、电话、学号、学院、专业、班级、年级、入学年份、毕业年份

- 账号状态管理：启用/禁用学生账号，禁用后该账号无法登录系统

- 数据概览：统计学生总数、活动总数、报名总数、待审核报名数等核心指标

- 学分分布统计：按学分分类统计已获得学分总量与要求学分数，展示各分类学分分布情况

- 学生学分统计：统计每位学生的总已获得学分、总要求学分及是否存在学分预警

- 活动统计：按活动分类统计活动数量与总参与人数，展示各分类活动热度

- 学院学分统计：按学院统计学生人数、预警人数及预警率，展示各学院学分完成情况

- 通知发送：向指定学生或全体学生发送通知消息，设置通知类型与内容

- 文件上传：支持上传图片等文件，自动按日期分目录存储并生成访问URL
 
### 技术栈

后端框架Spring Boot 3.x
ORM框架MyBatis-Plus（含分页插件、逻辑删除、自动填充）
权限认证Spring Security + JWT（无状态认证、角色鉴权）
前端框架Vue 3
构建工具Vite
数据库MySQL 8.x（含sys_user、student_info、activity、activity_registration、credit_category、credit_record、notification等数据表）
密码加密BCryptPasswordEncoder
参数校验Jakarta Validation
接口文档RESTful API + JSON
